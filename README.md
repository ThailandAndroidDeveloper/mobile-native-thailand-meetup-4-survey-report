# Mobile Native Thailand Meetup #4 Survey Report

Poll results from the attendees of Mobile Native Thailand Meetup #4 (21 October 2026).

Live page: https://thailandandroiddeveloper.github.io/mobile-native-thailand-meetup-4-survey-report/

- **Results** tab: every question with the share of people who chose each option.
- **Post images** tab: the 1080 × 1350 poster for each question.

The results are votes from event attendees only and are not suitable for statistical use.

## Structure

- `site/` is the static site that gets published (plain HTML and JavaScript, no build step).
- `site/data.js` holds the poll numbers.
- `.github/workflows/deploy-github-pages.yml` publishes `site/` to GitHub Pages and to the `gh-pages` branch.
